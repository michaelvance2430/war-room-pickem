# War Room native iOS app

This directory is the canonical native SwiftUI application used for Simulator, TestFlight, and App Store builds.

- Open `WarRoom.xcodeproj` in Xcode.
- Use the `WarRoom` scheme.
- Do not replace this app with the Capacitor/web wrapper in `../ios/App`.
- Database migrations supporting the native app live in `Database/`.

The native history was consolidated into the main War Room repository on August 19, 2026 so the production iOS source and the existing web archive are both backed up without overwriting either history.
