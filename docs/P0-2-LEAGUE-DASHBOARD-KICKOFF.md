# P0.2 — League Dashboard (kickoff guardrails)

**Status:** In progress · execution against Product Architecture Freeze  
**Mission:** The League page becomes the place a commissioner **wants** to visit every week.

---

## Success test

When a commissioner opens League, they immediately know:

1. What needs my attention?  
2. What is happening this week?  
3. What are my people doing?  
4. Where are my league settings?  

Nothing else competes.

---

## Permanent rule

The League page is **not** a control panel.  
It is the **front porch** of the league.

Host opens the door to their football season — not league software.

---

## Information hierarchy (frozen)

1. Hero  
2. This Week  
3. The Room  
4. League Settings  

No additional peer-level sections.

---

## Object permanence

This Week card is sacred. Never disappears. Status changes:

Draft → Live → Needs scoring → Scored / Archive  

Object remains.

---

## Constraints (this pass)

- **Do not** implement Season Opening  
- **Do not** implement Moments framework  
- **Do not** add personality systems (Gazette rewrite, cheevo systems, etc.)  

Only perfect the **weekly hosting** experience.

---

## Actively demote / remove

Documentation · onboarding leftovers · admin software · internal terminology · checklists · multiple competing CTAs  

Calmer, not busier.

---

| Section | Question |
